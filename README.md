# customer_behavior_analysis
Data Analytics project using Python, SQL, and Power BI to transform raw data into actionable insights through analysis and interactive visualizations.

The project workflow includes:
- Loading dataset using Python
- Data cleaning and preprocessing
- Performing Exploratory Data Analysis (EDA)
- Running SQL queries using PostgreSQL/MySQL/SQL Server
- Building an interactive Power BI dashboard
- Creating insights and reports
- Preparing a presentation using Gamma
